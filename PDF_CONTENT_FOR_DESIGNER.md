## DESIGN SPECIFICATIONS FOR DESIGNER

### Color Codes (HSL Format)
- **Yellow:** hsl(48, 96%, 53%) - Fast Executor
- **Red:** hsl(0, 84%, 60%) - Creative Motivator
- **Green:** hsl(142, 71%, 45%) - Logical Systems Thinker
- **Blue:** hsl(221, 83%, 53%) - Empathetic Connector

### Layout Requirements
- **Paper Size:** A4 (210mm × 297mm) or US Letter (8.5" × 11")
- **Orientation:** Portrait
- **Margins:** 20mm all sides
- **Bleed:** 3mm (if printing)

### Typography Guidelines
- **Headers:** Bold, Sans-serif (18-36pt)
- **Body Text:** Regular, Sans-serif (10-12pt)
- **Color Names:** Bold, Large (24-28pt)
- **Accent Text:** Match user's color theme

### Variable Content (Create Placeholders)
The following content changes per user:
- `{{USER_COLOR_NAME}}` - Fast Executor, Creative Motivator, Logical Systems Thinker, or Empathetic Connector
- `{{GENERATION_DATE}}` - Current date
- `{{LEADERSHIP_SCORE}}` - Dynamic percentage (e.g., 85%)
- `{{COLOR_DESCRIPTION}}` - Yellow/Red/Green/Blue specific text
- `{{STRENGTHS_LIST}}` - Color-specific strengths (5 items)
- `{{DEVELOPMENT_AREAS}}` - Color-specific development areas (4 items)

### Design Elements Needed
1. Header banner with color gradient
2. Logo/icon placeholder (circular, 30mm diameter)
3. Color badge box (rounded corners, 80mm × 50mm)
4. Premium badge (rounded, 60mm × 20mm)
5. Progress bars for capability metrics (adjustable width)
6. Bullet point styling (circular dots matching color theme)
7. Section headers with background color fills
8. Footer design with contact information

### File Deliverables Required
1. **Adobe Illustrator file (.ai)** with layers and text as editable objects
2. **PDF template** with placeholder text clearly marked
3. **Individual assets** (SVG format): icons, badges, decorative elements
4. **Style guide** documenting fonts, colors, spacing rules
5. **Figma or Sketch file** (optional but helpful for handoff)

## NOTES FOR DESIGNER

- All text should be editable (not converted to outlines)
- Use color-coded design elements that can swap based on user's dominant color
- Keep consistent visual hierarchy across all 3 pages
- Ensure high readability - maintain good contrast ratios
- Professional yet approachable design aesthetic
- Include page numbers (1/3, 2/3, 3/3)
- Leave space for future additions (e.g., charts, graphs)
- Design should work well when printed in grayscale as fallback
